# {title}: poster notes

Read before the first batch of a session. The author's general poster style lives in the vault's `STYLE.md`; this file holds
what is specific to this poster.

## Where things are

- **Poster:** `{deck}`.
- **Source:** the paper (and an earlier poster, if any) every claim and number comes from.
- **Venue:** its size and orientation limit, the print and upload formats it asks for, and the dates.

## Facts and claims

Change a claim, number or result only when a comment asks and the paper supports it. List where each number comes from.

## People, logos and links

Authors, affiliations, logos, and what each QR code points to. Keep these exact.

## Actors and colours

How this poster maps its actors to colours, so every block keeps the same mapping.

## Conventions

Terms, notation and anything the author asked to keep fixed on this poster.
