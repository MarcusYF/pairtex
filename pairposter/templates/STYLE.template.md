# {name}'s poster style: the living guide

PairPoster keeps this file. Every agent that builds or revises a poster for {handle} reads it before the first block, and adds
to it after each batch from the evidence in `evidence.jsonl` (how: the skill's `references/learning.md`; seeding from past
posters: `references/seeding.md`). {handle} may edit it at any time; {handle}'s edits win.

The poster's visual look (palette, typeface, icon style) comes from PairDeck's style guide (`pairposter paths`: "visual
look") unless a rule below says otherwise; this guide holds what is particular to posters: what goes on one, how much, and
how it reads from two metres.

**Order of authority.** (1) The request or comment in front of you. (2) The venue's rules (size, orientation). (3) The base
rules below. (4) Confirmed rules. (5) Tentative patterns, applied only where the case clearly fits. (6) PairPoster's defaults
(`references/poster.md`). (7) General good practice. Facts bound all of these: style never changes a claim, a number or a
result.
