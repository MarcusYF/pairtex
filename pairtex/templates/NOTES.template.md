# {title}: project notes

Read before the first batch of a session. General writing preferences live in the style vault's `STYLE.md`; this file holds what
is specific to this paper.

## Where things are

- **Main file:** `{main}`.
- **Source of truth:** the backend in `project.json` (Overleaf, a git remote or a local folder). The loop edits its own checkout
  (`repo/`) and publishes from there.

## Facts and claims

Change a claim, number, theorem statement or citation only when a comment asks and a source supports it. List the sources here:
results files, the facts behind each table, the bibliography the paper may cite.

## Terms and notation

The paper's own terms and symbols, with where each is defined. Check how a term is used in the paper before introducing a new one.

## Conventions

- Protected notes (`protected_macros` in `project.json`): coauthors' note macros the loop never removes or rewrites.
- Rules from the project's own guidelines that bind every edit.

## Answering questions (`%?`)

Where the reasons behind the text are recorded: earlier drafts (`earlier_versions` in `project.json`), outlines, change logs,
review responses.
