# {title}: talk notes

Read before the first batch of a session. How {slug} should be built and given lives in the style vault's `STYLE.md`; this
file holds what is specific to this talk.

## The talk

- **Folder:** `{talk}` (slides in `slides/`, one file per slide; the script in `SCRIPT.md`).
- **Slot:** {minutes} minutes. At about 140 spoken words a minute, that is the script's budget.
- **Audience and venue:** who will be in the room, what they know, what the session is called.

## Facts and claims

Change a claim, a number, a theorem or a figure's data only when a comment asks and a source supports it. List the sources:
the paper, the results files, the data behind each chart.

## Terms and symbols

The talk's own terms and symbols, as the paper uses them, and the colour each recurring object has on the slides.

## Decisions

Choices the author made for this talk (structure, what moved to the backup, what not to change), with the date.
